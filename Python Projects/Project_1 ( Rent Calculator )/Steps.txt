Steps of Rent Calculator Project –

1) Input Collection  
The program first asks the user to enter :-
	Flat rent (rent) 
	Current electricity meter reading (electricity_current_unit_reading) 
	Previous electricity meter reading (electricity_previous_unit_reading) 
	Charge per electricity unit (charge_per_unit)  
	Water charges (water_charge) 
( Note – These inputs are taken as integers using int(input(...)). )

2) Electricity Units Calculation  
	Formula : calculated_ electricity_ unit = electricity_ current_ unit_ reading - electricity_ previous_ unit_ reading
	This gives the number of electricity units consumed during the billing period. 
	The program prints : "Electricity unit spend :"

3) Electricity Bill Calculation  
	Formula : total_electricity_bill = calculated_electricity_unit * charge_per_unit 
	This gives the total electricity bill. 
	The program prints : "Electricity bill : "

4) Water Charges  
	Water charges are directly taken from user input (water_charge).
	Assigned to water_charge_bill. 
	The program prints : "Water charges : "

5) Total Rent Calculation  
	Formula : total_rent = rent + total_electricity_bill + water_charge_bill 
	This gives the final amount the renter has to pay. 
	The program prints : "The renter want to pay the rent : " 

6) End Message  
	Finally, the program prints : "Thank you ..."
